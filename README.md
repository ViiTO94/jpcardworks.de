# JP CardWorks

Website für JP CardWorks.

Enthalten:
- `index.html` – Startseite
- `impressum.html` – vorläufige Impressum-Seite
- `datenschutz.html` – vorläufige Datenschutzerklärung

Vor dem öffentlichen gewerblichen Betrieb müssen die Platzhalter im Impressum ergänzt und die Datenschutzerklärung an das tatsächliche Hosting angepasst werden.
